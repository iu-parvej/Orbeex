# Acceptable Use Policy

**Last updated: 2026-10-17**

Orbeex is provided as open-source software. This policy sets expectations for responsible
use. It applies to use of the official software and project resources.

## Intended use

Orbeex is intended for lawful geospatial analysis, mapping, and data processing.

## Prohibited use

Do not use Orbeex to:

- violate any applicable law or regulation;
- infringe the rights of others, including privacy and intellectual-property rights;
- process data you are not authorized to access;
- cause harm, including through the creation of misleading maps or analyses presented as
  authoritative when they are not.

## AI features

When using AI features:

- You are responsible for the model provider's terms and costs.
- You are responsible for reviewing proposed operations before execution, particularly
  destructive ones.
- Do not send data to a model provider that you are not permitted to disclose to that
  provider.

## No warranty

Orbeex is provided "as is", without warranty of any kind, as stated in the
[Apache-2.0 license](../LICENSE). Outputs of spatial analysis must be verified before use in
decisions with real-world consequences.

## Reporting

Report misuse of the project's name or resources as described in
[TRADEMARK.md](TRADEMARK.md) and [SECURITY.md](../SECURITY.md).
