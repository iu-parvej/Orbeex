# Trademark Policy

**Last updated: 2026-10-17**

This policy covers use of the Orbeex name and logo. It is separate from the software
license: the Apache-2.0 license grants rights to the code, not to the project's trademarks.

## Trademarks

The name "Orbeex" and the Orbeex logo are trademarks of the Orbeex project. The Apache-2.0
license does not grant permission to use these marks.

## Permitted use without permission

You may use the name "Orbeex" to:

- refer to the project truthfully, for example "built with Orbeex" or "compatible with
  Orbeex";
- describe an unmodified copy of the software;
- link to the official project.

## Use requiring permission

Permission is required to:

- use the name or logo in a way that implies endorsement, sponsorship, or official status;
- use the marks in a product name, company name, or domain name;
- distribute a modified version under the Orbeex name.

Modified versions must use a different name and must not suggest they are the official
project.

## Forks and distributions

Forks are permitted under the software license. A fork that is distributed publicly must:

- use a distinct name that does not include "Orbeex";
- not use the Orbeex logo;
- state clearly that it is a modified version and is not the official project.

## Reporting misuse

Report trademark misuse by opening an issue in the repository.
