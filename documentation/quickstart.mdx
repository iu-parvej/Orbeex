# Getting Started

Orbeex is in active development. This page describes the first public release. Exact download links will appear here when it ships — you can also watch the project repository for release announcements.

## What you will need

| | Requirement |
|---|---|
| Computer | Windows 10/11, macOS 12+, or a current Linux distribution |
| Disk space | A few hundred megabytes for the application |
| Internet | Only for downloading the app and (optionally) AI features — the software itself runs offline |
| AI account | Optional. Only if you want AI features. You use your own account and key |

## The first-session flow

Once installed, a typical first session looks like this:

1. **Open Orbeex.**
2. **Open a map file** — drag in a GeoPackage, GeoJSON, or GeoTIFF file, or browse for it. Your map appears.
3. **Explore** — zoom, pan, click features to see their details.
4. **Ask for something** — type a request in plain language, or use the tools directly. For bigger tasks, Orbeex shows you the plan first.
5. **Approve and run.**
6. **Save or export** your result.

That is the whole loop. Nothing is uploaded, nothing is shared.

## Do you need AI?

No. AI features simply save you from building steps by hand — beginners get results faster, and experienced users skip repetitive work. Without AI, Orbeex is a complete, quiet, offline map-analysis tool.

If you do want AI: open settings, choose a provider (OpenAI, Anthropic's Claude, Google Gemini, DeepSeek, Qwen, or a local model), and paste your own API key. Details: [Using AI with Orbeex](/working-with-ai).
