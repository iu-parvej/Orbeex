# Support

## Getting help

- **Documentation:** the public docs site (see `docs-site/`).
- **Questions & discussion:** GitHub Discussions.
- **Bug reports:** GitHub Issues (use the bug report template).
- **Feature requests:** GitHub Issues (use the feature request template).

## Before opening an issue

1. Search existing issues and discussions.
2. Check the documentation and `MASTER_BLUEPRINT.md`.
3. Include version/commit, OS, steps to reproduce, and relevant logs/config.

## Security issues

**Do not** open a public issue. See [SECURITY.md](SECURITY.md).

## Scope of support

Orbeex is community-supported. There is no commercial support SLA in this phase. Enterprise
support options may be introduced later; see `plan/`.
