decision, write a new ADR that supersedes the old one (Blueprint §3.3).
Naming: `ADR-NNNN-<slug>.md`.

## Status Legend

- **Accepted** — current decision; binding.
- **Superseded by NNNN** — historical; follow the superseding ADR.
- **Proposed** — under discussion; not yet binding.
- **Rejected** — considered and declined (retained for rationale).
