# The Operation Graph

> **Everything is an Operation.** Every action in Orbeex — human or AI, desktop or web,
> core or plugin — reduces to an `Operation` node in an append-only operation graph.

## Why it matters

A single abstraction gives Orbeex, for free:

- **Undo / redo** — move a cursor in the graph.
- **Auditability** — every change is a logged node with a reasoning trace.
- **Reproducibility** — replays are deterministic.
- **Scripting** — the graph is serializable and machine-authorable.
- **Incremental recompute** — changing a node recomputes only its downstream dependents.
- **AI safety** — the AI proposes a graph; the engine validates and executes it.

## How the AI uses it

```
Natural language → Intent → Plan (draft Operation Graph)
    → Safety Gate (type + policy + cost) → Human confirmation → Deterministic execution
```

The AI **never** mutates data directly. It emits a typed plan that the engine validates.
This is the firewall between probabilistic and deterministic systems.
