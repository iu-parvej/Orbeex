# Quickstart

:::note
Orbeex is in active development. Installation instructions will be published here at the
first public release.
:::

## Planned steps

1. Install Orbeex for your platform (Windows, macOS, Linux).
2. Add an LLM API key (or point to a local model) — keys stay on your machine.
3. Open a dataset (GeoPackage, FlatGeobuf, GeoJSON, GeoTIFF…).
4. Describe what you want in natural language.
5. Review the proposed plan, then confirm and execute.

## Requirements (planned)

| Platform | Requirement |
|---|---|
| Windows | 10/11, 64-bit |
| macOS | 12+ |
| Linux | Modern distro, x86_64 |
