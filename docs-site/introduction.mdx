# Orbeex

Orbeex is an open-source, **AI-native Geographic Information System** built in Rust. It
turns natural language into **reviewable, reversible, auditable geospatial operations**,
executed by a high-performance native engine — on desktop and in the browser (WASM) — with
**zero vendor lock-in** on the LLM tier.

## Why Orbeex

- **Agentic GIS** — describe a task in plain language; Orbeex plans, proposes, confirms, and executes.
- **Deterministic & auditable** — every action is an `Operation` in an append-only graph.
- **Fast** — native Rust engine, GPU rendering, target < 100 ms viewport @ 10M features.
- **Sovereign** — your data stays local; only intent/schema is sent to LLMs (opt-in).
- **Multi-LLM** — OpenAI, Claude, Gemini, DeepSeek, Qwen, and local models.
