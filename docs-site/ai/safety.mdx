# Safety & Guardrails

GIS is a domain where one wrong transform can be costly. Orbeex makes AI actions
**reviewable, reversible, and auditable** by design.

## Risk tiers

| Tier | Behavior | Examples |
|---|---|---|
| **Safe** (read-only) | Auto-execute; undo available | Zoom, query, summarize |
| **Additive** | Show plan; one-click confirm | Add layer; new derived layer |
| **Destructive** | Mandatory review + dry-run + backup | Overwrite file; delete features |

## Hard limits

- Max operation-graph depth
- Max affected features per auto-run
- Max LLM spend per session (cost governor, hard stop)
- No file overwrites without explicit confirmation
- Every autonomous action logged with a full reasoning trace

## Sovereignty

Raw data never leaves your machine unless you opt in. See [LLM Providers](/ai/providers).
