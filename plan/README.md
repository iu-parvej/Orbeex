# plan/ — Roadmap & Strategic Execution

This directory houses the full project roadmap and strategic execution plan.

**Scope:** WHAT we will build and WHEN. Forward-looking.
**Not here:** decisions (→ `brain/decisions/`), research evidence (→ `research/`).

## Contents

| Path | Purpose |
|---|---|
| `vision/` | Long-term product vision & strategy |
| `roadmap/phases/` | Phase-by-phase plan (P0…P7) |
| `roadmap/milestones/` | Milestone definitions + exit criteria |
| `execution/` | Sprints, work breakdown, schedules |
| `releases/` | Release planning (what ships in which version) |
| `metrics/` | KPIs, performance budgets, tracked targets |

**Protocol:** Never delete historical plans. Mark `STATUS: SUPERSEDED` and link the successor.
